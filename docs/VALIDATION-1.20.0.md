# 1.20.0 验证记录

本次验收设备：PHK110（OnePlus Ace），Android 真机。全程不导出手机截图、GIF 或录屏。

## 实现

- 整屏截图采用虚线选框相机；快捷设置为三条滑轨；长截图、区域截图与滚动截图的剪刀保留空心指环。调整移动区域、录制分辨率、录制全屏、锁屏和关于图标。
- 应用弹窗按钮的背景左右内缩 5dp；快捷管理控制之间保留 8dp 布局间距，常用符号按钮与长截图选中工具的背景也保留间隔。
- 检查更新以弹窗呈现，保留应用内下载与安装校验；关于空叶使用独立的可滚动页面。
- 透明 PNG 与 GIF 根据可见边界显示，GIF 分析所有帧，并对不透明增量帧保持正确处理。原文件不重编码、不改变播放时序；已有尺寸按可见比例换算，限制在 36–150dp。
- 实际悬浮窗和位置预览均使用归一化后的宽高，保留长宽比；0dp 按可见图案贴边，负距离仍可部分隐藏。
- 应用图标填满快捷圆圈，并用主色补足透明角落；最近应用降低饱和度并适当提亮。
- 文件选择器使用独立透明任务，关闭预览窗口和过渡动画；当前 Ace 使用系统自带的 OPlus 文件选择器，未读取或导出其文件列表。
- 「自动滚动长截图」统一缩为「滚动截图」。录屏选区为全屏时，全屏按钮禁用并置灰，缩小后可重新选择。
