## 测试中修正的问题

- Sony 屏幕边缘返回手势抢占截图手柄：为小窗口增加公开 API 的手势避让区域。
- 底部手柄与导航区域冲突：将中间手柄向框内移动，工具条向上错开。
- 连续添加时旧缩略图位图释放过早：先清空旧 ImageView，再移除窗口和回收位图；结果窗口也统一清空图片引用。修复后完整三张添加、预览、编辑、保存通过。
- 验收入口的 SINGLE_TOP 启动可能回到已有主页面：改用 CLEAR_TOP 明确进入程序生成的测试页。
- 截图回调增加 8 秒超时恢复；普通系统配置刷新不取消截图，只有实际旋转或锁屏才取消未保存会话。
