# v1.30.5 手势覆盖、边距与翻译恢复

日期：2026-11-02。设备：用户指定的 Ace2（PHK110）。版本：1.30.5，versionCode 55。

## 调整

- 打开空叶的 Intent 增加 NO_ANIMATION，启动时使用无额外系统进出动画的 ActivityOptions；软件只执行原有从下向上的内容覆盖动画，不添加对角位移或缩放。透明主/关于页主题关闭窗口动画，API 34+ 同时关闭进出 Activity 过渡。退后台后的动画覆盖在 moveTaskToBack 调用之后立即执行，消除系统额外退场动画；1.30.4 的旧窗口遮蔽、固定透明过渡层、透明末帧提交保留。
- 边框距离计算、配置读取和滑块上限统一增加到 200%。100% 仍为贴边，200% 向内留出一个悬浮球宽度；下限 30%、大小 30%–500% 不变。
- 翻译分为检测、模型准备、模型下载及实际翻译，检测 4 秒仍无结果时按支持的文字类型回退，避免短词停在检测状态。模型与翻译均有可重试的超时状态，过期请求不能覆盖新结果。
- 本次复现包含两层下载问题：旧网络访问模型服务超时，随后旧下载任务继续等待；重试后 Ace2 系统下载器仍报告排队等待 Wi-Fi，尽管当前网络为 Wi-Fi。显式重试只通过 SDK 公共 API 重置尚未下载成功的模型，保留已下载模型；当前已连 Wi-Fi 时去掉多余下载器过滤，其他网络仍要求 Wi-Fi。没有改用云端翻译接口、伪造译文或内置测试词典。
- 翻译图标的“中”和“A”使用一致的矢量字形、描边和底色，避免小字号系统中文字体造成显示差异；前方字卡保持覆盖后方字卡。
