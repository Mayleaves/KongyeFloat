## 修改与验证证据

### 首页非满行布局和排序

原空位使用普通 View 与 WRAP_CONTENT 高度，测量时会请求当前可用视口高度，导致只有 3 个或末行 1 个时整行/卡片被撑大。新增 HomeToolGrid：每行四个等宽位置、110dp 行高，空位高度明确为 0。首页仍按内容高度包裹，不足一行不会出现大段空白。

真机分别配置 3 个和 5 个工具：卡片高度分别为约 126dp 和 236dp（含上下内边距），列间距一致；长按“录屏”跨行拖到首位后，保存顺序为 record/region/longshot/auto_longshot/screenshot，重新打开应用仍保留。拖动不触发工具点击，支持在列表边缘自动滚动；离开界面时终止滚动回调。原管理多选、取消和恢复默认继续保留。

### Ace 区域截图十字

原实现把 WindowManager 参数当作实际球体位置，又直接把屏幕坐标画到提示窗口本地坐标中。现在从球体 getLocationOnScreen 取得实际位置，在绘制时再扣除提示层屏幕原点；每次绘制刷新位置，避免刚更新窗口时使用旧帧位置。

Ace 实际按住拖动后，球体真实左上角 (621,1171)，十字屏幕位置 (550,1100)，差值均为 71px，即当前密度下的 24dp。测试后恢复原位置 (1118,1129)，尺寸 41dp、不透明度 73%、边距 0 保持。红色/黄色、未变黄松手不截图、变黄后框选的逻辑未改；十字不带阴影。

### 更新和 GitHub 占位

“外观 → 其他”加入检查更新和 GitHub。点击分别显示待接入、待配置的说明对话框，不进行网络请求、下载、仓库跳转，也不报告已经是最新版本。Debug 真机两入口均验证。

### 操作反馈

系统 Toast 可能处于增强悬浮层下方。新增统一 Feedback：使用本应用当前的悬浮层显示约 2.8 秒文字提示，不获取焦点、不拦截触摸；普通悬浮窗透明度不超过系统默认允许穿透阈值。没有可用悬浮权限时回退系统 Toast。后续消息替换旧提示，迟到的旧定时器不会关闭新提示。

复制、追加便签、图片保存、视频/GIF 保存以及工具错误改用可见反馈。保存先报告处理中，文件 API 成功返回 URI 后才报告成功，失败则报告失败；录制结果同时保留操作状态文字。复制捕获剪贴板调用异常，不在失败时显示成功。分享仍使用系统选择器，不提示已准备临时分享、不宣称已发送。
