- Debug、五种架构 Release 构建和 Release Lint 通过；ARM64、ARMv7、x86、x86_64、通用版均通过正式签名校验。
- 18 项 JVM 字幕检查通过，包括姓名与对话分离、跨行段落合并、缩进选项续行、B/C 选项分组、相近字号归一、字色和背景取色、中文间隙整理与中英混排空格。
