# 1.21.0 验证记录

设备：PHK110（OnePlus Ace）。保留原配置，全程未导出手机截图、GIF 或录屏。

## 修改

- 整屏截图采用屏幕与空心剪刀图标；GIF 文字按摄像机主体框居中；「主页」工具采用指定描边房屋；关于图标使用与其他图标一致的 1.7 线宽。
- 「打开空叶软件页面」缩为「打开空叶」，保留再次触发收起页面的行为。
- 大小使用 100%–500%，以可见长边 36dp 为 100%；边框距离使用 30%–100%，表示留在屏幕内的宽度比例。旧 dp 配置自动换算，0dp 对应 100%，150dp 约为 417%。
- 去掉工具触发后首页的无条件延迟重建；文件选择器返回时状态未变就保留原首页视图。文件宿主为透明、浮动、无过渡窗口。
- 区域截图先展示实时选择框，确认后才获取画面。应用管理的悬浮窗口关闭系统窗口动画。
- 长截图切换方向只更新方向按钮与缩略预览，保留选区、拖动控制、工具栏窗口。
- 长列表弹窗居中，最高为屏幕高度的 84%，还会考虑系统栏与键盘；底部动作按钮高 36dp，并保留间隔和底部留白。
- 更新检查确认本地版本不低于公开版本时显示「已是最新版本」，有可下载更新时显示「更新」；正常状态无「重新检查」，错误状态提供「重试」。

## 品牌与盆栽

- 1.svg 转为原生软件图标及自适应图标；2.svg 的滑入、叶片旋转、几何底板和文字浮现转为原生 Canvas 动画，约 1.6 秒。桌面图标入口播放，手势入口不强制播放；进程恢复与配置重建区分处理。
- 六张盆栽 SVG 转为原生 vector，位于首页标题行右侧。06–09 发芽，09–12 成长，12–15 茂盛，15–18 花苞，18–21 开花，21–次日06 枯萎休息；按本地时间每分钟核对并在页面显示时刷新。
- 8 份原 SVG 保存在 app/src/main/assets/branding，与提供的原文件逐字节一致，正式 APK 中也完整保留；没有外部图片或网页加载。
