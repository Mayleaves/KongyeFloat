# 1.30.9 存储精简验证

日期：2026-11-02。设备：Ace2 PHK110，支持 ABI 为 arm64-v8a、armeabi-v7a。正式版 1.30.9（59）已覆盖安装，保留原设置。

## 范围与占用

1.30.8 通用 APK 包含四套原生库。按 ZIP 内数据测量，x86_64、x86、ARMv7 库压缩后合计约 99.8 MiB；ARM64 设备不需要这些副本。本次构建按架构输出完整 APK，保留通用构建，不裁减功能、识别模型或当前设备的原生库。

| 1.30.8 通用 | 157,605,995 | 157.61 |
| 1.30.9 ARM64 | 52,951,341 | 52.95 |
| 1.30.9 ARMv7 | 49,006,239 | 49.01 |
| 1.30.9 x86 | 62,425,487 | 62.43 |
| 1.30.9 x86_64 | 68,571,696 | 68.57 |
| 1.30.9 通用 | 157,607,143 | 157.61 |

Ace2 安装包缩小约 66.4%，减少 104,654,654 字节。以上是 APK 文件大小，不能直接当作系统“应用＋数据＋缓存”总占用或运行内存。设备代码目录的 `du` 查询被系统权限限制，未声称得到安装后全部应用字节的精确对比。一次优化前进程 PSS 约 85.5 MiB、Swap PSS 约 45.6 MiB，仅是当时快照；本次没有以不同时刻 PSS 波动声称运行内存收益。

另外清理上次自制字体测试留下的两个测试文件（25,928,940、11,779,732 字节），合计 37,708,672 字节。清理前确认精确路径；没有删除用户 GIF、图片或其他数据。清理后 `files` 目录按 `du` 报告为 4 KiB。已下载翻译模型保留，保证离线翻译能力。

## 不改变功能的检查

- 同一构建的 ARM64 与通用包，除 Manifest、签名和其他架构库外，所有公共文件逐项 SHA-256 相同。
- ARM64 的七个原生库与通用版逐项相同：C++ 运行库、ML Kit OCR、语言检测、翻译、ONNX Runtime 及 JNI、OpenCV。
- 两个 PaddleOCR ONNX 模型与 1.30.8 的 SHA-256 相同，未量化、降精度或移除。
- 调试版使用生产识别流程运行已知霞鹜文楷图片；姓名、中文标点、小数、网址和原文按位置融合回归通过。
- 正式版确认选择 arm64-v8a，签名校验通过，覆盖安装成功，非 debug，原尺寸、边框距离、不透明度保留，首页和设置启动正常。

打包核对原始记录见 [packaging-1.30.9.json](benchmarks/packaging-1.30.9.json)。未枚举每一项既有功能重新测试；主要风险在架构分发，已验证原生库完整性与实际双引擎调用。

## 更新与清理

- 根据 `Build.SUPPORTED_ABIS` 顺序选最合适的架构包；不选择其他 CPU 包，兼容通用版及历史无架构后缀发布包。
- 新增后台清理，只处理私有 updates 目录中的完整、可解析、包名匹配且版本不高于当前版本的 APK。未完成文件、未来版本、其他应用 APK、损坏文件和不符合命名规则的文件保留。
- 清理按进程执行一次，不阻塞主线程；失败不影响打开应用。不清理录制、分享媒体、模型、设置和便签。
