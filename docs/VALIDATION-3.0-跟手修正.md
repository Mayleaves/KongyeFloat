# v3.0 横向拉出响应修正

日期：2026-11-10。基于 v3.0，保留原有形变和回边动画，不采用之前已撤回的 HTML 弹簧跟随方案。

明确横向移动超过 8 dp 误触范围后立即进入拖动，直接使用手指位移更新位置；纵向或方向不明确的移动仍保留 280 ms 判定，避免抢占上下轻划。静止长按仍为 650 ms。

- `GestureRulesCheck` 28 项、`CapturePointerCheck` 41 项通过。
- 索尼 A202SO / HQ629V0361：实际左右横向拖动首次进入拖动分别为 67 ms、82 ms；拖动请求位置与手指位移一致，原形变结束后缩放恢复 1，移动后松手未进入截图。上下轻划未误判为拖动。
- 静止长按仍打开边缘快捷，松手关闭。采样读取时 ADB 曾中断；恢复连接后读取已完成的 93 帧采样确认长按成立，并确认快捷已关闭。
- 已恢复索尼原有大小、边距、位置、触感、淡化、自定义外观及手势设置。未导出手机截图或录屏。
- Debug / Release 构建、Lint、五个正式包的签名及架构检查通过；正式包不含调试接收器或触控采样类。版本号保持 3.0，替换原 v3.0 发布文件。

索尼原装 v1.30.2 使用旧证书，因此仅给索尼测试 APK 使用匹配的原有 `kongye-release.jks` 签名，以保留数据覆盖安装。项目 `signing.properties` 未修改。该 APK 是索尼兼容测试包，不应替代 GitHub 正式发布包。

正式发布包沿用 GitHub v3.0 的既有签名；与索尼临时兼容测试签名分开。原 v3.0 用户需手动重新下载覆盖，同版本号不会触发应用内的新版本提醒。
