## 修复中发现的回归

- 直接将原内容设为 INVISIBLE 会影响视频纹理，因此最终改为透明度渐变，并以更高层级的胶囊接收点击，原内容保持挂载。
- 对已准备但尚未开始播放的 MediaPlayer 调用 pause 会令播放器失效。最终只在实际播放时暂停；重新执行整套验收，未播放状态的收起/展开及后续播放通过。
- 先前失败日志没有计入通过数量。
