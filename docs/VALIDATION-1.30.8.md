# 1.30.8 验证记录

日期：2026-11-02。设备：Ace2 PHK110。版本：1.30.8（58）。

## 实现范围

- 保留 1.30.7 的无障碍原文与截图 OCR 按位置融合，原生文字优先。
- 增加 PaddleOCR 官方 PP-OCRv5_mobile 检测、识别模型，结合现有 ML Kit。模型随 APK 提供，识别不上传图片、不依赖联网下载。
- 对应区域以 PaddleOCR 中文结果为主，保留 ML Kit 独有区域，以及两引擎一致且可靠的拉丁文字排版；低置信度结果有回退。
- 新增默认开启的“中文标点优化”，只调整 OCR 文本，不改无障碍原文。切换选项使用缓存结果，不重新识别。小数、时间、网址和英文语句有保留规则；不会补造漏识别的引号。
- 原有保留换行开关与原文/截图混合识别继续可用。

来源与许可证见 [OCR-ENGINES.md](OCR-ENGINES.md)、[UPSTREAM.md](../paddle-ocr/UPSTREAM.md) 和 [MODELS.json](../paddle-ocr/MODELS.json)。PaddleOCR SDK 固定于 dab3fe35379033fdcb2d0e9572fac0b36c9a9ebf；使用 ONNX Runtime Android 1.21.1、官方 OpenCV Android 4.12.0。

## 自制样例对比

同一 Ace2 上分别用 Android sans-serif、霞鹜文楷和楷体生成图片；每种字体测试 28、40 px。每个样例含六行已知文字，包括中文姓名、中文标点、引号、小数、时间、英文和网址。总计 714 个字符，忽略空白，标点计入编辑距离。比较原 ML Kit、PaddleOCR 原始结果与最终融合并优化标点的结果。

| sans-serif | 28 | 16 | 1 | 0 |
| sans-serif | 40 | 16 | 0 | 0 |
| 霞鹜文楷 | 28 | 17 | 0 | 0 |

这是有限的自制测试集，不代表所有屏幕、字体或标点的识别准确率。仓耳今楷没有可用字体文件，本次没有测试。测试字体文件未随项目或 APK 分发。原始结果与计算摘要见 [ocr-1.30.8.json](benchmarks/ocr-1.30.8.json)。

样例的 ML Kit 单次耗时约 0.73–1.73 秒，PaddleOCR 单次推理约 0.98–1.66 秒；PaddleOCR 对比过程复用同一会话，该数据不包含每次模型加载，也不是生产双引擎端到端延迟。应用实际依次执行两引擎，耗时会增加。较长图片分块处理，工作在线程中执行，并支持关闭窗口后取消后续处理。

## 已知限制与安装包

实际区域结果测试中，`他说：“春风又绿江南岸。”` 仍出现漏后引号的情况，个别英文字符也可能混淆。标点优化是有限规则，复杂排版或中英混排仍需要人工复核。
