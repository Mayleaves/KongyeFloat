# 3.1.1 通知权限与截图保存修复

日期：2026-11-13。基线为工作区现有 3.1.0（versionCode 77），修复版本 3.1.1（versionCode 78）。已有密码页面识别改动保留，旧调试断言按当前 Snapshot 构造参数同步。

## 改动

- 移除 POST_NOTIFICATIONS 声明、首页通知权限胶囊、授权申请和通知设置跳转。首页权限只保留悬浮窗、无障碍。
- 保留 Android 必需的前台服务通知。Android 13+ 不调用普通通知更新；旧版系统仅在通知可用时更新运行通知。录制完成不再额外发送结果通知。
- 通知不可用时忽略隐藏录制球的旧设置，保留录制球用于暂停和停止；设置页不引导用户申请通知。
- `RegionResult` 使用独立的 OCR 单线程队列，并设为后台优先级；图片保存、复制和分享继续使用原图片工作队列，不再排在 OCR 后面。
- OCR 仍处理独立位图副本。结果关闭时使识别令牌失效并关闭 OCR 队列；正在保存的原图在写入结束后才回收。
- 选区工具条直接保存时跳过无障碍文字读取；保存、复制和分享准备立即给出处理中反馈。保存仍是原始尺寸无损 PNG。

## 检查

- Debug / Release 构建与 Lint 通过（有既有警告）。现有本地逻辑检查 184 项通过。
- 五种正式架构输出均通过 APK 签名校验；正式 ARM64 包的最终权限列表没有 POST_NOTIFICATIONS。
- 测试设备为当前连接的 Ace2 PHK110；本次没有连接索尼，未将结果记为索尼验证。
- 调试专用 `CaptureExportCheckActivity` 使用 960×640 程序随机像素图，阻塞 OCR 队列后调用真实保存方法。OCR 未释放时保存完成，回读 PNG 尺寸及像素正确。
- 重复点击保存没有重入；保存排队时关闭结果，位图保留到任务完成，写入文件仍可读，之后位图回收、OCR 队列关闭。
- 测试仅保存程序生成的图片，校验后删除；恢复被测试覆盖的上次截图和结果窗口偏好。未导出屏幕内容、录屏或用户数据。
- `scripts/check-save-fix-device.py` 核对本应用首页的两个真实权限状态，确认无通知胶囊，并在未申请通知的情况下启动悬浮球。该脚本不截图。

## 边界

保存耗时仍取决于图片尺寸、PNG 压缩和手机存储速度，本次移除的是等待文字识别完成的排队时间。系统必需的前台运行提示和屏幕捕获授权没有绕过。录屏本次未启动屏幕捕获，控制球的通知兼容处理经过编译与静态检查。
