# v1.30.0 索尼验收

日期：2026-11-01。基线：Git 标签 v1.29.2。版本：1.30.0 / versionCode 50。设备：索尼 A202SO。1.29.3 未作为本次代码基线；其本地修改与记录归档在忽略的工作目录中。

## 修改与原因

- 检查 GitHub 确认最新公开正式版仍为 1.29.2，因此卸载本地测试包、回装 1.29.2 后显示最新，符合此前公开版本状态。此次对手动请求设置禁止缓存，并在结果窗口用实际安装版本重新比较，避免复用旧的比较值；高于公开版单独提示，不再显示“已是最新版本”。
- 保留 1.29.2 的标题动画与卡片出现节奏，在标题栏中新增盆栽独立容器；盆栽容器和内容共用 440ms 进度，方向、透明度、位移和缩放一致，原本的贴边定位及自身微动不受影响。
- 大小最小值下调到 30%，边框距离最大值提高到 150%；修改显示滑杆、设置读取、旧数值迁移和真实尺寸/边距换算。
- “外观与位置”移至卡片外，与“手势操作”使用相同 label；设置上方添加“悬浮基础”，与“界面主题”使用同一标题样式。

## 验证

- Debug/Release 构建、Android Lint、APK 签名校验通过。
- `tests/BallScaleCheck.java` 共 43 项百分比边界、连续边距换算、旧设置兼容与盆栽时段检查通过。
- `scripts/v130-sony-device.py` 在索尼通过 23 项检查，其中原生钩子包含 11 个版本/范围断言。实际滑杆达到 30% 大小、500% 大小、150% 和 30% 边距；真实悬浮球和预览均在 150% 时向内保留半个球宽。分组位置与字号/颜色正确；从设置、悬浮球回首页取样五帧，盆栽与内容同向同步，最后保持贴近卡片上沿。
- 生成发布信息验证“有新版本”“同版本”“高于公开版”三种状态；故意传入过时 comparison=0 仍按实际版本显示新版本和下载入口。没有执行下载。
- 索尼实际联网请求公开 GitHub 发布信息，以旧版 1.25.1 作为比较参数，返回公开版 1.29.2、comparison=1、可下载 APK，验证旧版比较能发现更新。
- 正式签名包覆盖安装后七项验收通过：正确版本与非调试标志、首页盆栽及权限条、外观标题、原尺寸/边距/透明度保持、悬浮基础位置、实际联网区分 1.30.0 本地版与 1.29.2 公开版、返回首页且无致命异常。
