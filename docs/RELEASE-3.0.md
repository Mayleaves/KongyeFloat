# 空叶悬浮球 3.0

## 2026-11-10 同版本跟手修正

- 横向拉出悬浮球超过误触范围后立即跟手，不再等待原来的 280 ms 判定；索尼实测约 67–82 ms 开始移动。
- 保留 v3.0 原有果冻形变和回边效果，上下轻划、长按及区域截图行为保留。
- 同步替换五个正式 APK 与 SHA-256 校验文件，沿用原 v3.0 发布签名。
- **版本号仍为 3.0。已安装原 v3.0 的用户请手动重新下载覆盖，同版本不会弹出新版本提醒。**

## 3.0 功能

- 新增「填充密码」：主动点击后连接同签名空叶文档密码空间，可匹配 / 搜索条目、按需解锁，再填入当前登录框。支持快捷菜单、边缘快捷和手势；首页可自行添加。
- 填充前重新核对应用、网页域名、窗口与输入框。页面变化、取消解锁或不支持写入时停止；不自动提交、不将密码复制到剪贴板。
- 首页默认八项沿用 v2.0.5 手机配置，已有自定义选择和顺序保留。
- 悬浮球从边缘向内拉出时加入果冻回弹，不改变截图指针坐标或最终大小。
- 区域、整屏和长截图结果新增复制图片，使用临时 PNG 内容链接，不额外保存到相册；复制成功后反馈并关闭窗口。
- 画面预览工具统一为一行四项：复制、分享、编辑、保存，采用相同浅色底。
