# 3.4.7 本地验证

版本 3.4.7，versionCode 111。

- Debug、五种架构 Release、Release Lint 通过。五种安装包的包名、版本和签名校验通过，签名与 3.4.6 一致。
- 在独占 Android 模拟器中使用系统目录选择器授权测试文件夹。通过界面保存并读取有效 ZIP，确认删除后文件消失。设置每周备份后触发 Android 定时任务，成功生成新备份，再关闭定时任务。
- 用本机 WebDAV 测试服务器通过界面测试连接、上传到 `KongyeFloat`、列表、下载、恢复与确认删除。设置每天备份并触发系统任务，服务器收到完整备份，再关闭定时任务。
- WebDAV 协议检查 20 项通过，包括配置加密、上传下载、并发覆盖防护、删除、异常文件与重定向处理。验收使用生成数据和测试账号。
- 定时任务在模拟器中手动触发，验证实际备份行为。实际运行时间由 Android 安排。未在真实手机或第三方 WebDAV 服务上测试。
