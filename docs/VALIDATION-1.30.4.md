# v1.30.4 退出末尾闪动修正

设备：用户指定的 Ace2（PHK110）。版本：1.30.4，versionCode 54。

## 调整

针对用户反馈“快退出完成时”软件画面闪动，延续 1.30.3 的真实桌面交接，修正末帧与窗口移除流程。

- 过渡首帧提交后，将本应用 Main/About 窗口设为不可见并降低窗口 alpha 至 0，等待两帧后退到后台。过渡结束后仍保持旧窗口隐藏，正常再次进入时恢复。
- 使用固定的透明 FrameLayout 承载软件窗口帧，只移动 ImageView 子项。根画布每次清除旧内容，避免移动整个窗口根节点后旧缓冲残留。
- 等待源窗口失去焦点后开始上移。结束时隐藏图像子项，提交完全透明的末帧，再等待两次 vsync 后移除临时窗口和释放内存图像。
- 捕获前停止未完成的进入动画，避免取帧与原窗口继续运动之间发生错位。原有 650ms 时长与曲线保留。
- 退出中途重新打开时取消旧过渡，恢复原页面与窗口可见状态。

窗口帧仅来自本应用自身的非安全窗口，通过 PixelCopy 保存在内存；不采集整个显示屏、其他应用或安全窗口，不申请屏幕录制授权，不写图像文件。异常情况保留回退路径。

## 验证

`scripts/v134-ace-device.py` 在 Ace2 通过 48 项检查，包含浅色首页、深色首页、深色关于页、退出中途重新进入和实际悬浮球上划：

- 动画尚在播放时真实 Launcher 已恢复前台，源窗口失去焦点，过渡层不抢焦点或触控。
- 整个上移期间及移除过渡层之后，原窗口保持隐藏。
- 同一个固定承载窗口持续存在，仅图像子项单调上移，没有中途重建窗口。
- 本应用过渡层内存自绘的 1 像素 alpha 采样显示：移出部分及最终帧均为透明；末帧提交记录来自本轮退出。
- 浅色首页、深色首页、深色关于页各记录 77 个移动阶段的 Choreographer 回调，间隔中位数及 P95 约 8.33–8.34ms。此数据反映回调调度，不能等同于显示器每帧实测呈现或替代主观流畅度评估。
- 再进入恢复同一个页面实例、原内容位置与窗口可见状态；快速重新打开没有遗留过渡窗口。
- 实际通过悬浮球上划打开，再次上划退出，最终保留真实桌面；当前进程没有致命异常。

测试只读取本应用控件/窗口元数据、内存自绘 alpha 数值及 Launcher 前台状态，没有导出手机截图、录屏或 GIF。仅调试验收期间让本应用窗口临时保持亮屏，结束后清除该标志，没有修改系统自动锁屏时间；测试配置及服务原运行状态已恢复。

Debug 与 Release 构建、Android Lint、APK 签名校验通过。正式包覆盖安装至 Ace2 后，另通过六项验收：版本与非调试标志、首页盆栽和权限条、外观标题、原大小/边距/透明度保留、悬浮基础分组、返回首页无致命异常。
