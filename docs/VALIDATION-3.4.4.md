# 3.4.4 本地验证

日期：2026-11-17。版本：3.4.4 / versionCode 108。包含 3.4.3 的字幕分句、残留人称 I 修正和默认样式调整。

- Debug、五种架构 Release 构建与 Release Lint 通过；正式 APK 经签名校验。
- 在独立 Android 模拟器中，使用两个自行生成的独立测试应用模拟游戏对白与翻译应用。翻译测试应用没有网络权限，没有向真实翻译服务发送内容。
- 「重新识别」重新读取选区后继续离线翻译；空白选区留在本应用，显示失败原因。
- 处理文字方式只传递本次选区原文，不带截图；交接期间暂停捕获。外部返回译文后，用户确认才显示到原对白上。
- 面板重建后保留编辑中的译文；错误请求标识及会话结束后的旧请求不能提交。
- 不返回结果的翻译应用支持复制、返回、主动粘贴；取消面板后恢复字幕会话。
- 另用仅支持分享文字的测试应用验证系统分享入口、复制粘贴返回与显示流程。
- 回到原游戏后核对对白；对白变化时拒绝旧译文，下一段继续自动离线翻译。
- 实际旋转模拟器至横屏，打开键盘并查看截图：采用紧凑面板，禁用键盘全屏编辑，输入区及返回/显示按钮保留在键盘上方。屏幕边界通过面板内部留白计算，避免居中布局叠加外边距导致向上偏移。

本次没有安装或操作真实手机，没有验证具体第三方翻译产品的兼容性、联网可用性或剧情翻译质量。外部应用是否支持接收、返回以及翻译效果由该应用决定；当前入口每次手动重译一段，并非连续自动联网翻译。
