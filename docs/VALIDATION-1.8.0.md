## 本次修改与实测

- 悬浮球支持 36–150dp，边框距离 −100–0dp。真机最大窗口宽 394px，负距离窗口实际超出物理屏幕；设置随后恢复为原 48dp、0dp。
- 拖动截图时球体窗口允许越过边框，左上十字跟随手指。真机黄十字锁定 (600,1200) 后拖到 (0,0)，实际区域结果为 600×1200。红十字阶段松手不截图；截图后球体回到原 (954,1087)–(1080,1213)。
- 录屏和 GIF 均移除右上问号。GIF 工具最后一项改为水印，增加隐藏录制图标；隐藏后仍可通过通知控制。
- 水印与图片文字共用实时画布输入逻辑。真机直接在选定位置弹出键盘，文字序列化为相对位置、字号、颜色；测试对象为 `1234`，位置约 x=0.5796、y=0.8205，字号约为高度的 0.02394。视频/GIF 都完成实际录制；手机内解码确认视频水印像素存在。支持多个文字对象、再选中、移动、删除、等比缩放与颜色。
- 水印工具和画布合并到同一焦点窗口，键盘出现时画布避让；完成后录制准备界面继续显示水印位置预览，开始捕获前移除这些准备窗口，实际水印由编码层绘制。
- 视频播放器改为 TextureView + MediaPlayer：播放按钮与进度/时长每 200ms 同步，拖进度可定位。真机验证播放推进、暂停冻结和跳转；实际收到 8 帧、时间 708ms 的一次样本，确认画面确实输出到纹理。
- 处理 Sony 播放完成后 getCurrentPosition 返回约 100ms 的情况：完成时固定显示总时长，重播/跳转再释放结束状态；真机 9791ms 片段播放后 position=9791、playing=false。进度文字只在内容改变时刷新，暂停后不再重复触发布局/无障碍事件。转换入口独立读取真实视频时长，实际视频转 2 秒 GIF 成功。
- 点视频直接进入大图播放，画面宽超过 900px、高超过 1500px，可双指缩放/移动及双击缩放；手机内注入双指事件确认纹理缩放超过 2 倍。播完后进入大图再播放可从头重播（2869ms 片段重播到 736ms，收到 7 帧、playing=true）。
- 快捷管理与录制结果使用各自独立的透明任务。真机从桌面长按进入快捷管理不唤起 MainActivity，关闭回桌面；从桌面录制 GIF 结束后，预览后面没有主界面窗口，关闭仍回原桌面。
