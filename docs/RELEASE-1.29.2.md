# 空叶悬浮球 1.29.2

本次发布包含 1.25.1 之后的更新，最新版本为 **1.29.2**。

- 修复翻译原文、译文的长文字单行溢出，改为自动换行与独立纵向滚动；增加“原文 / 译文”标题、不同卡片底色和绿色译文标记。
- 修复首页工具长按拖动时出现灰色矩形的问题，拖动图像外围透明，仅保留图标和名称；排序在原页面中保存。
- 快捷菜单增加原位勾选显隐、全选/全不选、拖动排序，菜单与首页配置独立；修复编辑角标裁切。
- 优化区域截图识别：优先提取选区内可访问原文，纯图片使用原图分块 OCR；默认去换行，可选择保留。识别完成直接更新原文字控件。
- 翻译进入后自动检测并翻译，支持中、英、日、韩及双方交换，窗口和按钮更紧凑。
- 录屏/GIF 支持分辨率、GIF 帧率、视频比特率及独立声音选择；水印、控制球显示和预览流程优化，计时位于录制球下方。
- 置顶浮窗可移出半个屏幕后收为图标胶囊，点击展开，保留窗口、浏览器 WebView 和播放器；修复未开始播放时错误暂停的问题。
- 滚动截图完成后进入画面预览，图片编辑应用后回到结果卡片，长截图保留单张删除及拖动排序。
- 统一软件进入/退出动画，关于页可整组退出并恢复；调整萤火闪烁、浮窗边框阴影等细节。

验证：Ace PHK110 真机验证；本次翻译修复的 23 项长文本交互检查和 7 项正式包检查通过；此前首页拖动、菜单、录屏/GIF 与浮窗验证记录一并保留。Debug/Release 构建、Android Lint 及签名校验通过。详细记录见仓库 docs 下对应版本。
