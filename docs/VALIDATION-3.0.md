# 空叶悬浮球 3.0 验证

日期：2026-11-10。设备：Ace2 PHK110，Android 16。基线：手机 v2.0.5 / versionCode 74；本次 versionName 3.0 / versionCode 75。

## 实现范围

完成共享任务文档第 4 节。首页默认八项采用开发前从手机界面核对的顺序：区域截图、长截图、录屏、字幕翻译、最近软件、常用软件、便签、浏览器；已有用户自定义选择保持独立，不强制重置。

新增主动触发的密码填充、列表搜索、同签名 Provider 调用和解锁返回重试、应用 / 域名 / 窗口 / 输入框一致性核对、成功后关联。无障碍事件仍只有 typeWindowStateChanged，增加 flagReportViewIds 以读取浏览器地址控件。密码仅在 reveal 响应和 ACTION_SET_TEXT 时临时使用，不进入日志、文件、偏好设置或剪贴板。

新增边缘向内拉出时的果冻动画，不改变窗口大小与截图指针坐标。截图结果一行四项：复制、分享、编辑、保存，统一浅色底；复制采用私有临时 PNG URI，不写相册，成功后提示并关闭结果。

## 验证结果

Debug / Release 构建与 Android Lint 通过；五个正式架构包签名验证通过，保持既有同签名证书。

`scripts/v3-ace-device.py` 的 22 项断言通过，包括：

- 域名解析、来源校验、默认八项、快捷与手势入口；打开列表不 reveal。
- 同签名隔离 Provider + 模拟登录页的直接填入、没有匹配时手动搜索及键盘关闭后的定位、首次关联。
- 模拟解锁成功后重新取窗口再填；取消解锁不填。
- 不支持 ACTION_SET_TEXT、窗口变化、同窗口域名变化、disabled / denied / not_found、取消列表均不误填。
- 区域、整屏、长截图的生成图片可复制为真实 PNG 内容 URI，并关闭窗口。
- 真实向内拖动播放果冻形变，最终缩放恢复 1。

测试只使用独立 `com.kongye.docs.docktest` 模拟 Provider 和 `com.kongye.floatball.fillfixture` 模拟登录页的固定测试值。未读取用户的真实密码，未更改或卸载真实空叶文档；系统生物识别由空叶文档的实现负责，模拟解锁验证的是悬浮球的 PendingIntent / 返回 / 重试流程。未导出手机截图或录屏。

正式使用需支持接口 v1 且同签名的空叶文档，用户开启密码空间读取开关。自绘键盘、禁止 ACTION_SET_TEXT 的控件、地址栏无法访问的网页会拒绝填充，不会退回复制密码。

正式包覆盖安装后补验：截图结果的复制、分享、编辑、保存同一行且等宽，复制后关闭结果；确认 versionName 3.0、versionCode 75、不可调试。已移除本次安装的两个模拟测试包。
