遵照用户“不导出截图”的选择，未导出手机截图、录屏、音频。本轮使用程序生成内容测试；像素检查在手机内使用合成图像，只返回检查项数和布尔结果。缓存 URI 不公开导出提供者，只向系统分享目标授予单 URI 只读权限；应用已禁止云备份，缓存不是相册文件，超过 24 小时的旧缓存会在后续分享时清理。
