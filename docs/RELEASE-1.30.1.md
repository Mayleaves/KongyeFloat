# 空叶悬浮球 1.30.1

基于 1.29.2 更新，包含百分比范围、设置分组、更新提示和页面切换动画修复。

- 首页小盆栽跟随主卡片从下向上浮入、淡入，取消单独左右滑动；动画中盆栽底部贴着卡片上沿，避免被卡片遮挡。

- 悬浮球大小范围改为 30%–500%，边框距离改为 30%–150%，实际悬浮球与位置预览使用同一换算。
- “外观与位置”移到卡片上方，与“手势操作”使用相同标题样式；设置首组增加“悬浮基础”。
- 手动检查更新禁用响应缓存，并按实际安装版本重新比较，明确区分“有新版本”“版本一致”“高于公开版”。
