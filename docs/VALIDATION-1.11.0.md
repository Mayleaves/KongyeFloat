## 免 Root 实现

新增 `OverlayWindows`，仅管理本应用创建的悬浮视图。无障碍已连接且“外观 → 增强悬浮层”开启时，通过无障碍服务的 WindowManager 和系统授权的 token 创建 TYPE_ACCESSIBILITY_OVERLAY（2032）；否则使用 TYPE_APPLICATION_OVERLAY（2038）。新增开关默认开启；不需要 Root、Shizuku、解锁或修改系统。

球体、按住快捷、工具菜单、浏览器、区域/长截图及结果、录制准备/水印/控制/画面标注使用同一管理器。每个视图记录原所属管理器，用同一管理器更新/移除；连接或开关变化时迁移视图，清除旧 token 后由新管理器分配，并保留布局参数和原焦点。无障碍连接、解绑、销毁均更新宿主。连接不可用时回退普通层，恢复后再迁移；普通层仍需已有的悬浮窗权限。

保留现有每应用禁用/隐身规则、锁屏隐藏和录制时隐藏普通球的行为；此功能不宣称高于所有系统窗口，不解除 FLAG_SECURE 或设备/应用其他截图保护。系统明确返回安全窗口截图错误时给出对应原因；返回黑色画面时不自动判断失败，以免误判正常黑色内容。

## Sony 合成页面及交互验证

测试页面为 Debug 版本本应用生成的合成内容，不进入真实支付、密码或政务应用。

- 同一合成页面开启 `setHideOverlayWindows(true)`：普通层 2038 被隐藏；切到增强层 2032 后球体可见，并实际收到触摸事件。按住快捷也显示为 2032。
- 页面允许截图时，实际截图中合成红色区域采样计数 34,655；仅在内存统计后回收位图，没有导出。
- 同一页面增加 FLAG_SECURE 后，截图 API 在该 Sony 返回成功但受保护画面为黑色，红色计数为 0；没有取得受保护内容。增强球在截图结束后恢复显示。因此此版本仍无法保证所有安全页面可截图。
- 合成密码输入框弹出键盘；将测试球临时放到 y=2100 的键盘区域，窗口仍可见。随后关闭键盘并恢复原 y，不修改用户保存的位置。
- 模拟无障碍宿主暂时不可用时，球切到 2038；恢复宿主后切回 2032。连续 20 次宿主迁移后仍可见，窗口列表恰好一个球体，没有重复窗口。
- 工具菜单、浏览器、手动长截图工具条、区域截图选框均验证为 2032 且正常出现/关闭；浏览器置顶、收起、关闭通过。
- 录屏准备、水印编辑、位置预览和录制控制均为 2032。水印原位键盘输入、换色及确认返回通过；录制时普通球隐藏，录制球可拖动，取消后返回准备并恢复增强球。GIF 准备和实际录制完成后的结果预览通过。
- 原设置逐项保持：48dp、边距 0dp、(954,1087)–(1080,1213)、单击不执行、上划开关主页、下划不执行、720p 视频、240p GIF、无声、显示录制控制图标及必应。新开关保持开启。
