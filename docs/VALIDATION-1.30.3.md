# v1.30.3 打开空叶上滑退场交接

日期：2026-11-01。设备：用户指定的 Ace2（ADB 型号 PHK110）。版本：1.30.3，versionCode 53。

## 调整

旧实现先将 Activity 内容上移 650ms，结束后才调用 moveTaskToBack，真实桌面在退场末尾才恢复前台。基线检查显示 Activity 自身透明，未覆盖区域在内存自绘中也保持透明，因此没有把黑色画面误认作软件内绘制的黑色底图。

新实现由 AppExitLayer 在内存暂存本软件自己的窗口帧，等待过渡层首帧提交后，将本任务退到后台；再在桌面上方把软件帧上滑移出。背景是真实恢复前台的桌面/原应用，不拍摄或模拟桌面背景。交接时禁用额外系统关闭动画，退出完成后清除过渡窗口及内存图像。快速重新打开会取消未结束的退出层并恢复原页面。

PixelCopy 的来源仅为本应用的窗口，不采集整个屏幕或其他窗口；本应用自身安全窗口也不会进入此路径。不申请 MediaProjection，不写图片文件，不通过网络发送帧。无悬浮权限、内存或窗口创建失败时，回退为原生内容上滑，并在最后一帧后执行退后台。主界面/关于页显式使用透明主题与 RGBA 窗口。
