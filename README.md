# 空叶悬浮球

空叶悬浮球是一款 Android 快捷工具。在使用其他应用时，可以通过悬浮球打开工具菜单、截取画面、录屏或翻译字幕。

[下载最新正式版](https://github.com/Mayleaves/KongyeFloat/releases/latest) · [使用说明](docs/USER_GUIDE.md) · [所有版本](https://github.com/Mayleaves/KongyeFloat/releases)

## 主要功能

- **悬浮球与手势**：自定义单击、双击、长按和上下划动作，配置边缘快捷入口、球体外观和每个应用的显示方式。
- **截图与编辑**：支持整屏、区域、手动拼接和自动滚动长截图。截图可识别文字、直接保存或编辑，支持裁剪、标注和马赛克。
- **录屏与 GIF**：自选录制区域、分辨率、声音和水印。支持暂停、画面标注、预览和导出。通知权限开启时可从录屏通知操作，日常使用悬浮球没有常驻通知。
- **字幕与文字翻译**：可连续翻译指定区域的字幕，按选区和原文排版显示，支持调整字号、位置、字色和背景。
- **漫画翻译（试用）**：在浏览器阅读时，画面停稳后自动识别并覆盖普通气泡文字，支持日语、英语、韩语和竖排中文。可选离线翻译或填写兼容接口的 API Key。
- **跳过开屏广告**：在「应用内悬浮球」中开启，可按应用单独设置。通过无障碍识别开屏阶段的跳过按钮。
- **常用工具**：悬浮浏览器、最近应用、便签和密码填充。密码填充由用户主动触发，需要配合同签名的空叶文档。
- **备份与恢复**：支持本地和 WebDAV 备份，可分别设置自动备份频率，按需包含便签。

## 安装与权限

应用支持 Android 8.0 及以上。小米 17、一加等 64 位 ARM 手机选择 `arm64-v8a`，不确定架构时选择 `all-universal`。使用同一签名的安装包覆盖安装可保留已有设置。

1. 在首页开启悬浮窗权限，再开启悬浮球。
2. 需要后台稳定运行、系统导航、截图或字幕翻译时，请开启系统无障碍列表中的「#空叶悬浮球」。区域截图、长截图和字幕翻译需要 Android 11 及以上。
3. 录屏时按系统提示授权屏幕捕获。通知权限和麦克风权限按需开启。

## 数据保存

截图文字识别在设备上运行。离线翻译首次使用时会下载语言模型，随后在设备上处理。选择漫画 API 翻译时，识别出的文字会发送到用户配置的接口，API Key 加密保存在本机，不随设置备份导出。便签和设置保存在本机，可由用户导出或备份到指定的 WebDAV 服务器。应用检查更新时会访问 GitHub。

## 构建

使用 Android Studio 打开项目，配置 Android SDK，再运行 `gradlew.bat :app:assembleDebug`（Windows）或 `./gradlew :app:assembleDebug`。正式构建使用 `:app:assembleRelease -PkongyeSplitAbis=true` 输出分架构 APK 和通用 APK。正式签名配置由构建者在本机提供。
